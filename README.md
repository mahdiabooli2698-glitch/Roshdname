# رُشدنامه | دفتر رشد شخصی

اپ وب فارسی برای ثبت زندگی روزمره: مطالعه، ورزش، خواب، مالی، تودو، و **تحلیل هوشمند هزینه و بودجه**.

مناسب انتشار روی **GitHub Pages** — یک‌صفحه‌ای، بدون سرور اختصاصی (داده‌ها روی دستگاه و اختیاری Firebase).

---

## امکانات

| بخش | توضیح |
|-----|--------|
| گزارش روزانه | خاطره، دخل/خرج/پس‌انداز، مطالعه درسی، ورزش، خواب، کالری، ترید، برنامه‌ریزی |
| تقویم شمسی | علامت روزهای دارای گزارش |
| تودولیست | تاریخ شمسی + تکرار روتین (روزانه/هفتگی/ماهانه) |
| خلاصه هفتگی/ماهانه | نمودار، مقایسه دوره‌ها، درصد پیشرفت/پسرفت |
| مالی هوشمند | مانده ماه قبل، باقی‌مانده ماه بعد، نسبت خرج به دخل، نکات هوشمند |
| بودجه شخصی | سقف خرج، هدف پس‌انداز و دخل ماهانه + نوار پیشرفت |
| درس‌ها و نکات اشتباه | از گزارش مطالعه جمع می‌شود |
| پشتیبان | localStorage، خروجی JSON، بک‌آپ ابری با Google (Firebase) |
| PWA | نصب روی موبایل، کار نسبی آفلاین با `sw.js` |

## روش‌های تحلیل هزینه (درون اپ)

1. **نسبت خرج به دخل**  
   `خرج ÷ دخل × ۱۰۰` — نوار رنگی: زیر ۷۰٪ سبز، تا ۹۰٪ زرد، بالاتر قرمز.

2. **خالص دوره**  
   `دخل − خرج` — مثبت = مانده مفید، منفی = کسری.

3. **مانده انتقالی ماهانه**  
   - مانده از ماه قبل = خالص ماه قبل  
   - باقی‌مانده برای ماه بعد = مانده قبل + خالص این ماه  

4. **میانگین خرج روزانه**  
   `جمع خرج دوره ÷ تعداد روزهای دارای گزارش`

5. **مقایسه با دوره قبل**  
   درصد تغییر خرج/دخل/پس‌انداز نسبت به هفته یا ماه قبل.

6. **مقایسه با بودجه شخصی**  
   اگر در تنظیمات سقف/هدف تعریف شده باشد: درصد مصرف سقف خرج و میزان رسیدن به هدف پس‌انداز و دخل + هشدار تجاوز از سقف.

7. **خلاصه سالانه**  
   جمع دخل/خرج/پس‌انداز سال، میانگین ماهانه، ماه با بیشترین خرج و بهترین خالص، و نکات هوشمند روی کل سال.

> نکته: دسته‌بندی هزینه‌ها (خوراک، حمل‌ونقل و …) فعلاً در مدل داده نیست؛ تحلیل روی **جمع روزانه دخل/خرج/پس‌انداز** است. برای تحلیل عمیق‌تر می‌توان بعداً دسته به گزارش روزانه اضافه کرد.

## انتشار روی GitHub Pages

1. ریپوی جدید بساز (مثلاً `roshdnameh`).
2. محتویات همین پوشه را در ریشه ریپو (یا پوشه `docs`) آپلود کن.
3. **Settings → Pages → Deploy from branch** → شاخه `main` و پوشه `/ (root)` (یا `/docs`).
4. آدرس نهایی چیزی شبیه:
   `https://USERNAME.github.io/roshdnameh/`

### Firebase (اختیاری — بک‌آپ ابری)

در `index.html` مقدار `firebaseConfig` را از کنسول Firebase پر کن، Google Sign-in را روشن کن، و دامنه `USERNAME.github.io` را در **Authorized domains** اضافه کن.

بدون Firebase هم اپ کامل کار می‌کند (فقط روی همان دستگاه / خروجی JSON).
